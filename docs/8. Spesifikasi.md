# Spesifikasi — Modul 5 (Pemesanan dan Notifikasi)

## Tanggung jawab

Order pasca-menang lelang, dispute, notifikasi multi-channel, realtime STOMP.

## Fitur

- Order lifecycle & tracking
- Dispute: buyer buka, seller respons, admin resolve
- Notifikasi in-app, email, Web Push
- STOMP/SockJS realtime dengan otorisasi per user
- Konsumen `auction.ended.v1` (idempotent)
- Escrow payout terjadwal setelah konfirmasi buyer
- Auth event consumer (user disabled)

| Modul | Arah |
|-------|------|
| 3 Lelang | Event RabbitMQ |
| 4 Dompet | Payout/refund HTTP |
| 6 Frontend | REST + STOMP |
| 1 Auth | Event sesi/revoke |
