# Desain integrasi — Modul 5 (Escrow, dispute, notifikasi)

## Escrow settlement

| Aspek | Sebelum | Sesudah |
|-------|---------|---------|
| Payout | Langsung di handler, ambigu dollar/cents | `OrderPayoutScheduler` + `toCents` eksplisit |
| Trigger | Inline | Setelah `CONFIRMED` + grace period |

Komponen: `OrderPayoutScheduler`, `WalletClient.payoutSeller`.

## Dispute resolution

State machine: `DISPUTED` → respons seller → admin `resolve` → refund buyer atau lanjut konfirmasi seller.

## Notifikasi dual-channel

- Persist in-app + publish STOMP topic user
- Email / Web Push sesuai preferensi

Keamanan STOMP: [11. Keamanan stomp.md](./11. Keamanan stomp.md)

## Event masuk

- `AuctionOrderEventConsumer` — dedup `eventId`, buat order dari menang lelang
- `AuthEventConsumer` — penonaktifan user
