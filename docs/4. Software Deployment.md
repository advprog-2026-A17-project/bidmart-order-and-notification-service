# Software Deployment

## CI

[`.github/workflows/ci.yml`](../.github/workflows/ci.yml):

- `./gradlew clean test jacocoTestReport`
- Artifact `order-service-test-coverage`
- Sonar when `SONAR_TOKEN` configured

## Docker

- [`Dockerfile`](../Dockerfile)
- Compose: `order-notification-service` on `8084`
- Depends on: `order-db`, `rabbitmq`, `wallet-service`, `auth-service`

## Key environment variables

From `bidmart-infrastructure/docker-compose.yml`:

- `WALLET_SERVICE_URL`, `BIDMART_AUTH_BASE_URL`
- `BIDMART_PUSH_VAPID_PUBLIC_KEY`, `BIDMART_PUSH_VAPID_PRIVATE_KEY`
- `SPRING_MAIL_*` for SMTP notifications
- `APP_INTERNAL_SERVICE_TOKEN` / `GATEWAY_INTERNAL_TOKEN`

## Metrics

Prometheus job `bidmart-order-service` → port 8084 `/actuator/prometheus`.

## STOMP via gateway

`GATEWAY_ORDER_WS_SERVICE_URL: lb://order-notification-service` in gateway env.
