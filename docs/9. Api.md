# API — Modul 5 (Order & Notifikasi)

## Orders — `/api/v1/orders`

| Method | Path | Keterangan |
|--------|------|------------|
| POST | `/` | Buat order |
| GET | `/{orderId}` | Detail |
| PUT | `/{orderId}/status` | Update status pengiriman |
| POST | `/{orderId}/confirm` | Buyer konfirmasi terima |
| POST | `/{orderId}/dispute` | Buka dispute |
| POST | `/events/auction-won` | Internal (`X-Internal-Service-Token`) |

Lifecycle: `CREATED` → `PACKED` → `SHIPPED` → `DELIVERED` → `CONFIRMED` (atau `DISPUTED`).

## Notifications — `/api/v1/notifications`

| Method | Path |
|--------|------|
| GET | `/` |
| GET | `/{id}` |
| PATCH | `/{id}/read-status` |
| GET/PUT | `/preferences` |
| GET | `/push/vapid-public-key` |
| POST/DELETE | `/push/subscriptions` |

- Endpoint: `/ws/notifications` (via gateway modul 7)
